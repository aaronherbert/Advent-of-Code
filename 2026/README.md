# Advent of Code 2026

Everything for this year's puzzles lives here, one folder per day:

```
2026/
  day01/
    meta.json        title, how many parts are published, answers Advent of Code accepted
    results.json     per-language build/run timings, memory, and the answers each program printed
    python/solution.py
    rust/solution.rs
    go/solution.go
    ...              one folder per language (see config/languages.json)
```

The workflow writes these files; you normally do not edit them by hand. Puzzle text and your personal
puzzle input are never stored here.
